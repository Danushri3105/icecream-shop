# icecream-shop

Sweet Scoops is a visually appealing and user-friendly website designed for an ice cream shop. Built using pure HTML and CSS, this project showcases clean design, responsive layout, and essential web elements like navigation, search, login form, and contact section.

🌟 **Features**

Fully static front-end website

Navigation bar with menu links (Home, About, Menu, Contact)

Search bar with styled input

Login form with input validation placeholders

Social media icon section

“Contact Us” and descriptive hero section

Visually engaging theme using images, gradients, and color contrast

🛠️ **Tools & Technologies Used**

HTML5 – Page structure and content

CSS3 – Styling and layout

Google Fonts – Custom typography

Font Awesome / Icons – For social media icons (if used)
